# Research and prototype branches

Index of the `research/*` and `prototype/*` branches: one conclusion per branch and the command to read it. It does not copy the research; read the branch before researching again. Maintained by hand; `pnpm check:docs` only checks that the file exists and that `AGENTS.md` links it (a clone does not always bring every branch). Branch names stay as they were created.

List: `git branch -a -l '*research/*' '*prototype/*'`

## Prototype

The `prototype/*` branches are full copies of the repo with the prototype in its own folder or file (the Read column names it); they carry no conclusions file. Inspect: `git diff --stat main...<branch>`.

| Branch | Content | Read |
|---|---|---|

| `prototype/estetica-chrome` | Chrome look variants over layout F (`?variant=`, `?paleta=`); G chosen (islands: dock) with a neon palette in dark mode and islands resizable horizontally, vertically and diagonally. | `git show prototype/estetica-chrome:packages/cli/navegador/prototipo-estetica-chrome.html` |
| `prototype/render-hibrido` | Hybrid render: Nodes and Groups in HTML/CSS, Edges in an SVG layer, all under a single `transform`; 14 Themes (A-R) as declarative Layer data over Primitives, with patches by kind and state.
