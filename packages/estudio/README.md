# estudio
Browser app of `dev`: the page `diagrams dev` serves at `/` and `/_estudio/*` (user guide: `docs/guide/dev-ui.md`).

## What it does
- `navegador/` by feature (one folder each); `dev.tsx` boots and `estudio.tsx` only assembles. `marco/proveedores.tsx` wraps frame and canvas; the frame (`marco/marco.tsx`, chrome state with `useChrome()`, `--ui-*` tokens under `.ui-chrome` in `tokens.css`) defines no domain types, and outside `marco/` only types of its context are imported.
- Seams: the tab registry `marco/pestanas.tsx` (a new panel receives no props) and `useEstudio()` from `marco/contexto.ts` (`irAVista`, `abrirPestana`, `avisar`, `escribir`, `abrirCodigo`...), with `useCanalDelEditor()` and `usePrevisualizacionDeTema()` apart. Read by version: `marco/use-lectura-por-version.ts` (discards stale responses; `useInspectPorVersion`). Single listbox: `marco/use-listbox.ts` (`aria-activedescendant`; used by the View index, where the choice follows the arrows, and by the Theme gallery). The View goes in `#view=<id>` (`lienzo/hash-de-estudio.ts` translates the shell's `p` key).
- Commands: a single registry `COMANDOS` (`comandos/registro.ts`) from which come shortcuts (a single listener; scopes in `teclas.ts:resolverTecla`), the Finder (Mod+K) and help (`?`). A new command is an entry `{ id, nombre, teclas, ambito, ejecutar(estudio) }`; a button announces it with `<BotonConAtajo comando="id">`.
- Tour (`tour/`): "Start here" coachmarks, the non-modal `tour` dialog (the highlighted area stays live; a layer with the area cut out blocks the dimmed rest) of the frame (`abrirDialogo('tour')`, command "View tour" and a button in the `?` help). `paradas.tsx` is the fixed script, read from the Workspace when the tour opens; `visto.ts` remembers in `localStorage` (memory only if it throws, as over `file://`) that the "1-minute tour" pill was used or dismissed.
- Writing (`escritura/escritura.ts`, `escribir` from `useEstudio()`): the single path of actions that write (move, order, undo, redo, jump, set Theme, apply `fix`); owner of the current version, of the 409 (reloads and warns; retries once only if the request asks for it, like `issues/aplicar-fix.ts`) and of the notice; it flushes the editor save before moving the File history. The editor (`editor/`, CodeMirror 6) saves on its own: `guardado.ts:crearGuardador` (400 ms debounce, `aunqueNoCompile`) and `reconciliacion.ts` (`fusionarTresVias`) against external writes.
- History, Diffs and agent activity are per-client stores (`almacen.ts`, WeakMap; not in `useEstudio`): they are created on connect so the first SSE event is not lost. The projection of the Diff onto the canvas is pure (`diferencia/proyeccion.ts`). `navegador/cliente.ts`: the only piece with routes; validates everything with the protocol schemas (a malformed 2xx is a failure), never throws (`Lectura<T>`) and shares a single SSE connection (`escuchar`). `estudio/protocolo` re-exports the protocol of `canonical`. `estudio/contrato` (tests only): `probarContratoDeDev(crear)`, `devEnMemoria` (the Live workspace of `sesion` over `puertoEnMemoria`; only the transport is fake) and `eventosSobreFetch`.
- Export (`diagrams export`): the same app in read-only mode. `modo` (`marco/modo.ts`, prop of `<Estudio>`, `useEstudio().modo`) is the single flag: components read the derived capability `useEstudio().puedeEscribir` (`puedeEscribirEn`) instead of comparing the mode, registry entries with `soloEnDev` (tabs, top bar pills, commands, tour stops) are left out (and `soloEnExport` ones only show in the export), and the canvas and the Themes gallery do not write. `<Estudio cliente>` replaces `fetch` and `eventos` with the read-only client (`exportado/cliente-de-solo-lectura.ts`) over the data of `src/exportado.ts` (`capturarExportado`, through the `dev` API). The page is `exportado/pagina.tsx`; `src/html-de-exportado.ts` (`htmlDeExportado`) inlines it with the Worker code and the data; `exportado/layout.ts` starts the Worker from a Blob or runs it on the main thread.
- Build (`tsup` + `scripts/construir.ts`, which calls `estudio/construir`, the same entry the bench uses): `dist/estudio/` with `index.html`, `pagina.js` (the editor and the dialogs in `trozos/` on demand), `worker.js` (zod replaced by `worker/zod-inerte.ts`), `estilo.css` and `exportado.js` (the export page: one IIFE without the editor nor ELK); `activosDelEstudio()` gives their paths and `carpetaDelEstudio()` the folder. It also regenerates `navegador/editor/palabras-clave.ts` from the `dsl` grammar (committed; do not edit by hand).

## What it does not do
Serves nothing and does not touch the Workspace (server, disk and Theme `.tsx` are `cli`'s; the `/api/*` routes, `sesion`'s); does not draw (`render`, `shell`). Not in `NUCLEO`: it uses DOM, `fetch` and `EventSource`. No Tailwind nor shadcn: Base UI (pinned version) and own CSS.

## Depends on
`canonical`, `render`, `shell`, `sesion` (only `devEnMemoria`) and `layout` (today only in tests). External: `react`, `react-dom`, `zod`, `@base-ui/react`, CodeMirror 6 (`@codemirror/*`, `@lezer/highlight`; pinned versions); `esbuild` in the build; `vitest` as optional peer of `estudio/contrato`.

## Entry file
`packages/estudio/src/index.ts` (Node, with the export), `packages/estudio/src/protocolo.ts`, `packages/estudio/src/contrato.ts` and `packages/estudio/src/construir.ts`; the page boots in `packages/estudio/navegador/dev.tsx` and the Worker in `packages/estudio/navegador/worker/worker.ts`. Iterate: rebuild and reload.

`docs/adr/0004-pnpm-monorepo-and-packages.md` (`estudio` amendment) and `docs/adr/0007-interaction-and-edit-protocol.md`.

## Test
`pnpm --filter estudio test`: pure functions, the contract against `devEnMemoria` and the app in jsdom (`test/ayudas-de-ui.tsx:montarEstudio`, queries by role; `maxWorkers: 2`, fake timers for debounce and highlighting; tests do not import internal UI constants). Every new `dev` route goes into the contract. `cli` runs the same contract against the real `dev` and the single Chromium end-to-end (`packages/cli/test/e2e-estudio.test.ts`); marker position, scroll and drags are tested only there.
