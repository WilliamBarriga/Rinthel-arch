# Seguridad

Para reportar una vulnerabilidad, usa el reporte privado de GitHub: pestana **Security** del repo, boton **Report a vulnerability** (https://github.com/WilliamBarriga/Rinthel-arch/security/advisories/new). No abras un issue publico con los detalles.

El proyecto esta en version 0.x: solo se corrige la rama `main`.
