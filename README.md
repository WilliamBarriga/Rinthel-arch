# rinthel-arch

Sistema propio (React + TS) para escribir y renderizar diagramas grandes y detallados de cualquier proyecto. un proyecto externo es el primer caso de uso, no el unico.

Estado: primera entrega (architecture y flow) implementada. El mapa de decisiones vive en el issue #1. Glosario en `CONTEXT.md`, reglas de codigo en `docs/CODING.md`, decisiones en `docs/adr/`.

Ejemplo de uso real: `examples/un proyecto externo/` (mapa de un proyecto externo). Pruebas: `pnpm test`; umbrales de rendimiento: `pnpm bench`.

El tracker es GitHub Issues de este repo (mapa: issue #1, label `wayfinder:map`; tickets = sub-issues, dependencias nativas).
