# rinthel-arch

Sistema propio (React + TS) para escribir y renderizar diagramas grandes y detallados de cualquier proyecto. El ejemplo de `examples/rinthel-arch/` documenta este mismo repo.

Estado: primera entrega (architecture y flow) implementada. El mapa de decisiones vive en el issue #1. Glosario en `CONTEXT.md`, reglas de codigo en `docs/CODING.md`, decisiones en `docs/adr/`.

Ejemplo de uso real: `examples/rinthel-arch/` (el propio sistema documentado con su DSL). Pruebas: `pnpm test`; umbrales de rendimiento: `pnpm bench`.

El tracker es GitHub Issues de este repo (mapa: issue #1, label `wayfinder:map`; tickets = sub-issues, dependencias nativas).
